PDF AI Assistant

A Smart AI-powered PDF Q&A system using Streamlit, Groq, FAISS

Features

*Upload any PDF
*Ask questions in natural language
*Get AI-powered answers
*Fast retrieval using FAISS vector search
*AI summary of documents
*Cached responses for speed

Tech Stack

*Streamlit (UI)
*Groq API (LLM)
*FAISS (Vector DB)
*LangChain (RAG pipeline)
*HuggingFace Embeddings

Setup (Local)

bash
pip install -r requirements.txt
